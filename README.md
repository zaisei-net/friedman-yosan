# フリードマン予算構想

ミルトン・フリードマン「資本主義と自由」に示された政府の役割①〜⑩のみを正当な政府機能とし、令和8年度予算を出発点として財政規模半減（歳出GDP比37%→19%）を実現する予算案を構築するプロジェクト。

## 理論的根拠

フリードマンが認める政府の役割（これがMAX）：

| # | 役割 |
|---|------|
| ① | 法と秩序を維持すること |
| ② | 財産権を規定すること |
| ③ | 財産権やその他経済上のゲームのルールを修正するための手段として役立つこと |
| ④ | ③のルールの解釈をめぐる意見の対立を裁定すること |
| ⑤ | 契約の履行を強制すること |
| ⑥ | 競争を促進すること |
| ⑦ | 貨幣制度の枠組を用意すること |
| ⑧ | 技術的独占に対抗するための活動に従事すること |
| ⑨ | 政府の干渉を正当化するに足るほど重大であると一般に考えられる外部効果を克服するための活動に従事すること |
| ⑩ | 狂人、子供等の責任能力のない者を保護するために私的な慈善運動や個人の家庭の対象とならない場合、これを補足すること |

## 数値目標

| 指標 | 現状 | 目標 |
|------|------|------|
| 歳入/GDP | 36% | 18% |
| 歳出/GDP | 37% | 19% |

## 令和8年度 一般会計 試算結果（科目・項レベル）

| | 元の金額 | 削減後 | 削減率 |
|---|---|---|---|
| 一般会計（760科目） | 122.3兆円 | 59.1兆円 | **51.7%** |
| GDP比（名目GDP≒600兆円） | 20.4% | 9.8% | — |

> ※一般会計のGDP比が目標（19%）を下回るのは、地方・特別会計を含む総政府支出が37%であるため。

## 主な削減根拠

| 所管 | 削減率 | 主な判断 |
|---|---|---|
| 厚生労働省 | 86% | 年金・医療保険の強制制度廃止、ネガティブ所得税（NIT）で代替 |
| 農林水産省 | 95% | 農業補助金は比較優位に反する産業政策として廃止 |
| 経済産業省 | 91% | ⑥独禁法執行のみ残存。産業政策・補助金全廃 |
| デジタル庁 | 100% | 民間移行 |
| 防衛省 | 0% | ①安全保障として全額維持 |
| 裁判所・法務省 | 0% | ①②④⑤核心機能として全額維持 |

## ファイル構成

```
data/
  r8_ippan.xlsx           財務省 令和8年度一般会計予算（科目別内訳）
  r8_tokubetsu.xlsx       財務省 令和8年度特別会計予算
analysis/
  friedman_items.py       科目（項）レベル削減試算スクリプト
output/
  friedman_items_r8.csv   令和8年度 科目別削減試算結果（760行）
policy/
  item_policy.yaml        フリードマン分類ポリシー定義
```
