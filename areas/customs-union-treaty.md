# 開放型関税同盟条約 プロジェクト成果サマリー

## 決定済みの方針

- 日台に限定しない開放型の関税同盟を核とする域内市場協定とし、「国又は独立の関税地域」に加入を開放する
- FTAではなくCPTPPとは別個の協定とし、CPTPPを条約として組み込まず、自由化水準の比較基準としてのみ利用する
- 商品・サービス・資本・労働の4分野を自由化対象とし、財政・租税・社会保障・外交・防衛等の国家制度は統合せず各国の権限とする
- 超国家機関は設置せず、政府間共同委員会のみを置く。紛争解決は政府間協議＋仲裁とする
- 条約起草はDraft Articles方式（条番号＋規定内容の逐条整理）で進め、日本国内法制の「要綱」段階は挟まない
- 第2章に「自由流通の原則」（域外から適法に輸入され関税徴収済みの産品は原産地を問わず域内を自由流通できる）を置く。これにより第3章（原産地規則）・第4章（繊維及び繊維製品）は域内適用不要とし章自体を置かない
- 関税収入は徴収国帰属ではなく、人口・貿易量等に基づく加盟国間の再配分方式を採用する。EU型の超国家予算・共同予算化はせず、政府間共同委員会が配分基準を設定・改定する
- 第6章（貿易上の救済）は、通常の対第三国貿易救済措置（アンチダンピング等）は政府間共同委員会協議を経た共同発動に限定し、安全保障上の緊急措置のみ加盟国が個別発動できる（発動後は委員会への通報・事後審査に服する）。単一調査当局は置かず、各国当局が調査し委員会が調整する
- 第9章（投資）の投資家対国家紛争解決（ISDS）は維持するが、CPTPPの凍結項目にならい投資契約・投資許可違反を理由とする請求類型は対象外とし、内国民待遇・最恵国待遇・収用・待遇の最低基準違反に限定する
- 第12章はCPTPPの「ビジネス関係者の一時的入国」に加え、構想独自の「域内労働移動」をB節として拡張する（域内就労の自由化、社会保障は不統合で年金期間通算等の調整のみ、公務・安全保障職務は自国民限定可）
- 第17章（国有企業）は競争政策（16章）から独立させ、非商業的援助（政府補助）が域内市場に不当な悪影響を及ぼさないことを確保する規定を置く。対抗措置の具体的設計は横断的論点として保留
- 第18章（知的財産）は「対象外」から取り込みへ方針転換。CPTPP現行水準（特許期間調整・新薬データ保護・著作権保護期間延長等の義務を凍結したまま）を維持し、義務化を復活させない。構想の「規制の同一化ではなく相互承認」という設計原理と整合する選択
- CPTPPの凍結条項全般について、復活させずCPTPP現行水準をそのまま採用する方針を統一的に適用（第5.3条・附属書10-B・11章・13.21条・15.8条等）

## 主要な分析・発見事項

- 関税同盟における関税収入の帰属は、実例（ドイツ関税同盟＝人口比配分、EU＝共同予算化、SACU＝貿易量等に基づく再配分プール）を見ると、いずれも徴収国帰属方式を採らない。共通対外関税では通関港選択の恣意性により地理的に有利な国に収入が偏る歪みが生じるため
- メルコスールは対外共通関税に加盟国ごとの例外品目を認め、貿易救済措置も各国が個別実施する運用が実態。ただしこれが対外共通関税を骨抜きにし「不完全な関税同盟」と評される要因になっている。自由流通の原則を置く今回の設計では、この個別発動方式は貿易迂回リスクを増幅させるため、通常措置は共同発動に限定し、安全保障上の緊急措置のみ例外的に個別発動を認める設計に落ち着いた
- CPTPPはTPPの規定を原則取り込みつつ22項目を凍結しており、うち11項目が第18章（知的財産）に集中。特許期間調整・新薬データ保護・著作権保護期間延長など、いずれも米国主導の権利者保護強化型規定が凍結対象になっている
- CPTPP現行水準（凍結後）は、知的財産保護の義務化を後退させた状態にあり、これは「知的財産権を法定独占とみなし自由市場を歪めるものと捉える」自由主義の一系統（オーストリア学派・公共選択論系）と整合的である一方、「知的財産権も財産権保護の一種」とみなす系統とは対立する。構想全体の「規制の同一化ではなく相互承認」という設計方針からは、前者に寄る判断がより整合的
- 条約起草の実務段階は日本国内法制の「要綱」段階を経ない。EU・EAEUいずれも最初からArticle形式で交渉テキストを作成しており、今回の逐条整理（Draft Articles形式）はこの実務慣行に沿ったもの

## 未解決の論点・検討中の問い

- 第17.4条・17.6条（国有企業への非商業的援助が不当な悪影響を及ぼす場合の「対抗措置」）の具体的な制度設計。6章の共同貿易救済枠組みに統合するか、17章独自の対抗措置とするかは横断的論点として保留中
- 第19章（労働基準）を独立章として置くか、12章B節に含めた域内労働移動規定のみで足りるとするかは未確定
- 第25章（規制の整合性）・第26章（透明性及び腐敗行為の防止）の要否（要検討）
- 第2.9条（旧・規格等の相互承認）を8章に一本化した後の、2章と8章の小委員会統合の要否
- 5章・2章の小委員会統合の要否（保留）
- 第6.5条（貿易救済の経過規定）の具体的内容は未詳細化
- 20〜24章（環境・協力及び能力開発・競争力及びビジネス円滑化・開発・中小企業）は「不要」と仕分け済みだが、正式な確定判断はまだ
- 27〜30章（運用及び制度に関する規定・紛争解決・例外及び一般規定・最終規定）は骨子未着手

## キーワード・概念の定義

| 用語 | 定義 |
|------|------|
| 自由流通の原則 | 域外から適法に輸入され共通対外関税が徴収された産品は、その原産地のいかんを問わず、締約国領域内を自由に流通できるとする協定固有の中核規定（第2.5条）。これにより域内の原産地規則が不要になる |
| 共通対外関税 | 関税同盟の対外国境において全加盟国が共通して適用する関税率。附属書に関税表を置き、最低関税率を基準として設定する案 |
| Draft Articles方式 | 条番号（例：第9.9条）を付した規定内容の逐条整理という条約起草の作業形式。日本国内法制の「要綱」段階を経ず、最初から条文形式で検討を進める方式 |
| CPTPP現行水準 | TPP原案からCPTPPが定める22項目の凍結（適用停止）を経た後の、現に効力を持つ規定の水準。今回の協定における「CPTPP以上」の基準点となる |
| 政府間共同委員会 | 本協定運用のために設置する唯一の共同機関。超国家機関ではなく、協定運用・関税表の技術的改訂・税関協力・相互承認・統計・情報交換・紛争協議等に権限を限定し、課税権・予算権・一般的立法権は持たない |
| 国又は独立の関税地域 | 本協定への加入資格を持つ主体の一般的表現。台湾のWTO上の地位（独立の関税地域）を踏まえてCPTPPと同様の表現を採用 |
| 要綱 | 日本の内閣法制局審査で用いられる、法律案準備段階の文書形式（「〜については、…とすること」という文体で主体・要件・効果を確定させるもの）。条約起草の実務には存在しない段階であることを確認済み |
